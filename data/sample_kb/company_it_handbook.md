VPN Access

Remote connectivity and troubleshooting


1. VPN access request

User: How can I get VPN access to our retail company network?

Assistant: To request VPN access, submit an access request through the IT Service Portal. Select the VPN Access category, provide your employee ID and business justification, and submit the request. IT will review your request and provide access after approval.

2. VPN connection failure

User: My VPN is not connecting. What should I do?

Assistant: Please check your internet connection and verify that you are using the company-approved VPN client. Enter your corporate credentials and complete MFA if prompted. If the issue continues, restart the VPN client and contact the IT Service Desk with the error message.

3. VPN password issue

User: My VPN says incorrect username or password.

Assistant: Verify that you are using your corporate username and current password. If your password has expired or you have forgotten it, use the company password reset portal. Do not share your password with anyone. Contact IT if your credentials are correct but VPN access still fails.

4. VPN MFA prompt

User: VPN is asking for an MFA code. Where can I get it?

Assistant: Open your company-approved authenticator app and retrieve the current verification code, or approve the sign-in notification if your organization uses push MFA. Never share your MFA code with anyone. If you no longer have access to your registered device, contact IT for MFA recovery.

5. VPN access for a new employee

User: I am a new store employee. How can I access VPN?

Assistant: Your manager or authorized approver must request VPN access through the IT Service Portal. Once approved, IT will provision your access and share the approved setup instructions. Make sure your corporate account and MFA are active.

Password Reset Policy

Account recovery and password requirements


6. Forgot password

User: I forgot my company password. How do I reset it?

Assistant: Go to the corporate password self-service portal and select 'Forgot Password'. Enter your username, verify your identity using the approved recovery method, and create a new password. If self-service recovery is unavailable, contact the IT Service Desk.

7. Password expired

User: My password has expired. I cannot log in to the store system.

Assistant: Reset your password through the approved password self-service portal. After resetting it, sign in again using your new password. If your account remains locked or the store system does not accept the new password, contact IT support.

8. Password policy

User: What is the company password policy?

Assistant: Use a unique password for your corporate account and follow the password requirements displayed in the approved password reset portal. Do not reuse passwords from personal accounts or share your password. For the exact password length, expiry, and history requirements, refer to the current company password policy.

9. Account locked

User: My account is locked after multiple incorrect password attempts.

Assistant: Stop trying additional passwords. Use the approved account recovery portal if self-service unlock is available. Otherwise, contact the IT Service Desk and provide your employee ID and the error message. IT will verify your identity before unlocking the account.

10. Password reset without access to email

User: I cannot access my company email. How can I reset my password?

Assistant: If you cannot access your registered recovery method, contact the IT Service Desk for identity verification and password recovery. Do not provide your password or MFA code to anyone. IT will guide you through the approved recovery process.

MFA Support

Multi-factor authentication and device recovery



11. MFA enrollment

User: How do I set up MFA for my corporate account?

Assistant: Sign in to the company identity portal and open the MFA security settings. Select the company-approved authenticator method and follow the enrollment instructions. Complete the verification process to activate MFA. Contact IT if enrollment fails.

12. Lost mobile phone

User: I lost my phone and cannot approve MFA.

Assistant: Contact the IT Service Desk immediately and report that your MFA device is unavailable. IT will verify your identity and help you recover access or register an approved replacement device. Do not attempt to bypass MFA using unauthorized methods.

13. MFA code not working

User: My MFA code is not working when I log in.

Assistant: Check that you are using the current code from your authenticator app and that your device time is set automatically. If the code is still rejected, try the approved alternative verification method or contact IT support for assistance.

14. Unexpected MFA notification

User: I received an MFA approval request but I am not logging in.

Assistant: Deny the unexpected MFA request. Do not approve sign-in attempts that you did not initiate. Report the incident to IT Security or the Service Desk immediately, following the company security reporting procedure. If you entered your password into a suspicious page, report that too.

15. New phone MFA setup

User: I purchased a new phone. How do I move my MFA?

Assistant: Follow the company-approved MFA device replacement procedure. If your old device is still available, use the identity portal to register the new device. If you no longer have access to the old device, contact IT for verified MFA recovery and enrollment.

Software Installation

Approved software requests and installation



16. Software installation request

User: I need Microsoft Excel installed on my company laptop.

Assistant: Submit a software installation request through the IT Service Portal. Select Microsoft Excel or Microsoft 365, provide the business justification, and submit the request for approval. IT will install the approved software or provide the approved installation process.

17. Installing unauthorized software

User: Can I download software from any website on my office laptop?

Assistant: No. Install software only from company-approved sources and follow the IT software installation policy. Unauthorized software may create security and licensing risks. Submit a request through the IT Service Portal if you need a new application.

18. Software installation approval

User: My software installation request is pending approval. What should I do?

Assistant: Check your request status in the IT Service Portal. If manager approval is required, contact your manager or authorized approver. If the request remains pending beyond the expected processing time, contact IT support with the ticket number.

19. Software not launching

User: The application installed by IT is not opening.

Assistant: Restart your laptop and try opening the application again. If the issue continues, note the error message and application name. Contact the IT Service Desk and provide the software name, device details, and any error information.

20. Store POS software issue

User: Our store POS application is not working after an update.

Assistant: Report the issue to the Retail IT Support team immediately, including the store number, affected POS terminal, application name, and error message. Do not uninstall or modify POS software without IT authorization. Follow the approved incident procedure to restore store operations.
